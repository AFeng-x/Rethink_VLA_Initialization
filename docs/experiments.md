# Experiments

The repository organizes experiments around three axes:

1. Capability-level embodied VQA domains and compositions.
2. Parameter update strategy: LoRA vs Full Finetune.
3. Robot-data pretraining and staged initialization.

The representative benchmark recipes cover Libero-10, SimplerBridge, and RoboCasa GR1 Tabletop where supported by the upstream StarVLA environment.

Use result CSV files under `examples/results/` as templates for logging experiment outcomes.
